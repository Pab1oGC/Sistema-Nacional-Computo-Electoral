# 🧾 Sistema de Cómputo Oficial

## 📌 Descripción
Sistema encargado de generar los resultados oficiales de las elecciones mediante validación rigurosa de datos provenientes de actas transcritas en CSV.

Garantiza alta exactitud, trazabilidad completa y consistencia fuerte.

## 🚀 Funcionalidades
- Carga de archivos CSV oficiales
- Validación de datos (consistencia y reglas)
- Auditoría completa de cambios
- Registro de eventos
- Generación de resultados oficiales

## 🧠 Arquitectura
- CQRS (separación de lectura/escritura)
- Base de datos con consistencia fuerte

## ⚡ Características clave
- Alta exactitud
- Consistencia fuerte
- Trazabilidad completa
- Auditoría detallada

## 📂 Flujo
1. Se carga archivo CSV
2. Se valida la estructura
3. Se aplican reglas de consistencia
4. Se registran eventos
5. Se generan resultados oficiales

## 🔍 Validaciones
- Integridad de datos
- Validación cruzada
- Detección de inconsistencias
