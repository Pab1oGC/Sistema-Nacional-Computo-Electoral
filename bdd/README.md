# 🗄️ Sistema de Base de Datos Distribuida

## 📌 Descripción
Infraestructura de almacenamiento diseñada para soportar ambos sistemas (RRV y Cómputo Oficial), garantizando disponibilidad, escalabilidad y tolerancia a fallos.

## 🎯 Objetivos
- Alta disponibilidad
- Replicación de datos
- Tolerancia a fallos
- Escalabilidad horizontal

## 🧠 Arquitectura
- Cluster distribuido
- Replicación automática
- Failover automático
- Event Store para auditoría

## 🔁 Replicación
- Replicación síncrona (oficial)
- Replicación asíncrona (RRV)

## ⚡ Características
- Consistencia eventual (RRV)
- Consistencia fuerte (Oficial)
- Idempotencia en eventos
- Recuperación ante fallos
